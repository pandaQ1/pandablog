欢迎来到 Panda Blog！这是一个由 **Hugo** 驱动的纯静态博客，托管在 GitHub Pages 上。

## 怎么添加新文章？

只需要在 `content/posts/` 目录下新建一个 Markdown 文件（`.md`），文件开头写上元信息：

```markdown
+++
title = '我的文章标题'
date = 2026-10-02T12:00:00+08:00
tags = ['标签1', '标签2']
+++

正文内容……支持 **加粗**、*斜体*、[链接](https://github.com)、代码块、图片等。
```

保存后推送（push）到 GitHub，网站会**自动构建并发布**，全程无需服务器。
