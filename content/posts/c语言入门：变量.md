```c
#include <stdio.h>

int main()
{
    int a = 10;
    return 0;
}
```

**第四行 `int a;` 解释：**

- 这是一条语句，结尾必须使用英文分号 `;` 表示结束。
- 语句的作用是：定义了一个整型变量，变量名为 `a`。
- `a` 是变量名，本质是内存中的一块存储空间，用来存放数据。
- `int` 是关键字，表示整型，限定了变量 `a` 只能存储整数。

**第五行 `int b, c;` 解释：**

- 这也是一条语句，同样以分号 `;` 结尾。
- 语句的作用是：一条语句同时定义了两个整型变量，变量名分别为 `b` 和 `c`。
- `b` 和 `c` 都是变量名，`int` 同样将它们限定为整型。

**关于数据类型：**
数据类型是 C 语言中用于定义变量类别的关键字。除 `int`（整型）外，还有 `float`（单精度浮点型）、`double`（双精度浮点型）、`char`（字符型）、`short`（短整型）、`long`（长整型）以及修饰符 `signed`（有符号）、`unsigned`（无符号）等。

### 二、给变量初始化

```c
#include <stdio.h>

int main()
{
    int a = 10;
    return 0;
}
```

**第四行 `int a = 10;` 解释：**

- 这是一条语句，以分号 `;` 结束。
- 语句的作用是：定义了一个整型变量 `a`，并且在定义的同时将其初始化为 10。
- `a` 是变量名，用来存储数据；`int` 表示 `a` 为整型。
- `= 10` 是初始化操作，表示将整数 10 存入变量 `a` 中。定义后，`a` 的值就是 10。

---

### 三、变量给变量初始化

```c
#include <stdio.h>

int main()
{
    int a = 10;
    int b = a;
    return 0;
}
```

**第四行 `int a = 10;`** 定义了整型变量 `a` 并初始化为 10。

**第五行 `int b = a;` 解释：**

`b` 是变量名，`int` 限定 `b` 为整型。

这是一条语句，以分号 `;` 结束。

语句的作用是：定义了一个整型变量 `b`，并用已有变量 `a` 的值来初始化 `b`。

因为此时 `a` 的值是 10，所以初始化后 `b` 的值也是 10。

**总结：**

变量可以理解为一个**数据的容器**，它对应内存中的一块存储空间，用于存放数据。
对变量的操作，归根结底就是三种：

**引用变量** —— 通过变量名读取或修改其中存储的值，如 `int b = a;` 或 `a = 20;`

**定义变量** —— 声明变量的名称和数据类型，如 `int a;`

**初始化变量** —— 在定义时或定义后，给变量赋予初始值，如 `int a = 10;`
