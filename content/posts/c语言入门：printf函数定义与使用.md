用 `printf` 打印变量：让程序“开口说话”

先看一段最简单的示例——在屏幕上打印变量 `a` 的值 `10`：

```c
#include <stdio.h>
int main()
{
    int a = 10;
    printf("%d", a);
    return 0;
}
```

运行后，屏幕上会显示：10

下面来逐层拆解这段代码中 `printf` 的用法。

#### 1. `printf` 是什么？

`printf` 是 C语言标准库提供的**格式化输出函数**，作用是将数据按照我们指定的格式打印到屏幕上（标准输出设备）。

它的名字可以拆开理解：**print**（打印） + **f**（format，格式）。所以它不仅仅是输出一个值，而是可以控制输出的格式。

#### 2. 头文件与库函数

`printf` 并不是 C语言核心语法的一部分，它是由标准库提供的**库函数**。这个函数的声明和相关信息都存放在名为 `stdio.h` 的头文件（标准输入输出头文件）中。

因此，在使用 `printf` 之前，必须用预处理指令包含这个头文件：

```c
#include <stdio.h>
```

这行代码告诉编译器：“请把 `stdio.h` 中的所有内容引入到我的程序里”，之后我们就可以直接调用 `printf`，无需自己重新编写。

#### 3. 格式控制字符串与占位符

`printf` 的圆括号里可以写若干个参数，第一个参数**必须是字符串**，称为**格式控制字符串**。它规定了输出的样式，其中可以包含普通字符和**占位符**。

在我们的例子中：

```c
printf("%d", a);
```

- `"%d"` 是格式控制字符串；
- `%d` 是一个**占位符**（也叫格式说明符），它告诉 `printf`：“在这里用后面第一个参数的值，按照**有符号十进制整数**的格式输出”；
- `a` 就是要输出的实际变量。

常用的占位符与之前学习的数据类型一一对应：

| 占位符 | 含义 | 对应典型类型 |
| --- | --- | --- |
| `%d` | 有符号十进制整数 | `int`、`short`、`signed` 等 |
| `%u` | 无符号十进制整数 | `unsigned int` |
| `%f` | 单精度浮点数（十进制小数） | `float`（也用于 `double`） |
| `%lf` | 双精度浮点数（严格用于 `double`） | `double`（尤其在使用 `scanf` 时有区别） |
| `%c` | 单个字符 | `char` |
| `%s` | 字符串 | `char` 数组或字符串常量 |

#### 4. 更复杂的例子

一次可以输出多个变量，只需在格式字符串中放置多个占位符，并按顺序提供参数：

```c
int age = 20;
double score = 95.5;
printf("年龄：%d，成绩：%.1f\n", age, score);
```

输出：年龄：20，成绩：95.5

分析：

- 普通文字 `年龄：`、`，成绩：` 会原样打印；
- `%d` 对应第一个参数 `age`；
- `%.1f` 中的 `.1` 是附加格式，表示小数点后保留 1 位；
- 最后的 `\n` 是转义字符，代表换行，使光标移到下一行。

#### 5. 常犯错误提醒

- **占位符与参数类型不匹配**：如用 `%d` 输出 `double` 值，或参数数量少于占位符，会导致不可预知的错误输出甚至程序崩溃。
- **忘记包含 `stdio.h`**：某些编译器可能会给出隐式声明警告或直接报错。
- **混淆 `%f` 和 `%lf`**：在 `printf` 中输出 `double` 时使用 `%f` 通常能工作（因为 float 会被提升为 double），但为保持清晰和一致，建议输出 `double` 时用 `%lf`。

---

这样，我们就完成了从变量定义到使用 `printf` 输出值的完整衔接。你学到的 `printf` 将贯穿整个C语言的学习过程，是调试和与程序交互的第一扇窗口。
