```c
#include<stdio.h>

int main()

{

return 0;

}
```

**<mark>第一行代码解释 `#include <stdio.h>`</mark>**

这是一个**预处理指令**，不是“命令”。它的作用是在编译之前，把 `stdio.h` 这个头文件的内容原样包含到我们的代码中。
为了使用库函数，需要用 `#include` 指令将声明了对应函数的头文件包含进来。库函数是 C 语言标准库中已经写好的函数，我们只需要按照规则调用，无需自己定义。
比如想使用 `printf` 输出信息，就必须先包含 `stdio.h` 头文件，这样 `printf` 才能被正常使用。
使用库函数时必须遵循其调用规则，充分理解其参数和返回值。
`#include` 的常见形式有：`#include <头文件名>` 和 `#include "头文件名"`。

---

**<mark>第二行代码解释 `int main()`</mark>**

这是一个**函数定义**。函数的基本结构是：`返回值类型 函数名(参数列表) { 函数体 }`。**函数的意义是“一次定义，多次调用”，实现代码的复用。
`int` 表示整型，代表值是整数（不含小数）。此处 `int` 作为函数的返回值类型，意味着这个函数必须返回一个整数值。
`main` 是函数名，它是一个<strong>特殊的函数**，是整个程序的**入口**。程序启动时，操作系统会自动调用 `main` 函数，因此它被称为主函数。
需要区分的是：主函数是由我们定义、被系统调用的；而库函数是别人预先写好的、由我们主动调用的，二者性质不同。
括号 `()` 内可以定义参数，这里为空表示主函数没有接收任何命令行参数。

---

**<mark>第三行代码解释 `{`</mark>**

这是**左大括号**{，和最后的右大括号 `}` 配套，用来界定**函数体的范围**。它的作用是将若干条语句组合成一个整体，明确函数从哪里开始，而不仅仅是“规范代码”。

---

**<mark>第四行代码解释 `return 0;`</mark>**

这是一条语句，结尾必须用分号 `;` 表示结束。**`return 0;` 表示从主函数返回一个整数值 `0`。我们可以把函数调用想象成一个值：例如，如果有 `int a = 某函数();`，那么变量 `a` 得到的就是该函数返回的值。在主函数中，这个返回值会交给操作系统。
习惯上，`return 0;` 表示程序<strong>成功运行结束**，向操作系统报告“一切正常”；返回非 `0` 值通常表示程序以某种非正常状态退出，具体含义可以由程序自行定义。

---

**<mark>第五行代码解释 `}`</mark>**

这是**右大括号**}，与前面的左大括号{配对，表示主函数的函数体到此结束，界定了函数的作用域。

---

**总结**

最简单的 C 程序通常由**头文件包含**和**主函数**两部分构成。头文件提供库函数等支持，主函数是程序的入口与起点。只有在这个基础框架之上，我们才能添加更多代码逻辑，逐步构建出完整的程序。
